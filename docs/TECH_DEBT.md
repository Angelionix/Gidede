## Правила ведения техдолга

1. **Каждое решение с компромиссом** → новая запись в этот файл
2. **Приоритизация**: 🔴 Критический → 🟠 Высокий → 🟡 Средний → 🟢 Низкий
3. **Закрытие**: запись помечается как ✅ Resolved только когда долг реально устранён
4. **Пересмотр**: на каждом переходе между фазами пересматриваем все открытые записи
5. **Новая запись** должна содержать: описание, причину, влияние, план решения
