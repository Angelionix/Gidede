## 1. Общая характеристика книги

Данный документ — это компендиум (сборник) практических знаний по левел-дизайну, собранный автором Alex K из выступлений ветеранов индустирии на GDC, статей и личного опыта. Книга не является академическим трудом — это «записки левел-дизайнера», структурированные по ключевым темам. Основной источник — Михаил Кадиков (Crytek, Crysis, Hunt: Showdown), чей сайт level-design.ru автор называет «лучшим ресурсом по левел-дизайну, который он когда-либо видел».

**Уникальная ценность для Gidede**: Это единственный документ в библиотеке проекта, который системно покрывает **практический левел-дизайн от концепции до финализации** с акцентом на: (1) восприятие и читаемость пространства игроком, (2) управление навигацией без UI, (3) дизайн боевых пространств, (4) мультиплеерный левел-дизайн. Документ дополняет книгу Кадикова (Книга 11) более детальной проработкой тем читаемости, навигации и мультиплеера.

**Структура книги** — 5 крупных разделов:
1. 🔹 Planning — планирование уровня
2. 🔹 Navigation & Distinction — навигация и различимость
3. 🔹 Pacing — темп и ритм
4. 🔹 Enhancing the Experience — усиление впечатлений
5. 🔹 Designing for Combat — дизайн для боя
6. 🔹 Multiplayer Map Design — мультиплеерный дизайн

## 2. Ключевые концепции и модели

### Раздел 1: Планирование (Planning)

#### Концептуальный процесс

**Три столпа концепции уровня**:
1. **Ограничения (Restrictions)**: вещи, которые нужно сделать. Часто не определяются левел-дизайнером. Пример: «ввести новую механику», «использовать нового врага», «встреча с NPC в конце».
2. **Цели (Goals)**: вещи, которые хочется сделать. Тема уровня, вызовы, вертикальность, альтернативные маршруты.
3. **Контекст (Context)**: вещи, которые нужно учитывать. Позиция уровня в игре (7-й уровень ≈ середина), какие типы уровней уже запланированы.

**Зачем**: создаёт стартовую точку (избежать «проблемы чистого холста»), снижает риск переделок, создаёт структуру с самого начала, помогает команде планировать работу.

**Critical Path** = кратчайший маршрут прохождения уровня.
**Golden Path** = «предпочтительный» маршрут дизайнера, предлагающий оптимальный опыт.

**Ключевые вопросы при планировании**:
- Где происходит уровень? (Лес? Призрачный город? Франция?)
- Когда? (Полдень? Ночь? После битвы?)
- Каковы механики игры? (Уровень должен обслуживать геймплей)
- Почему игрок запомнит этот уровень? (Что выделяется?)
- Соответствует ли локация геймплею? (Снайперский бой в тесных коридорах = плохо)
- Какова «история» локации? (Что здесь произошло? Кто живёт?)
- Что нужно сообщить команде? (Программистам, художникам, саунд-дизайнерам)
- Возможен ли уровень? (Движок, время, ассеты)

#### Метрики (Metrics)

Фиксация всех ключевых измерений и их документация:
- Позволяет тестировать значения в быстром прототипе
- Гарантирует правильность укрытий, прыжков и т.д. с самого начала
- Позволяет художникам понимать, какие метрики важны для геймплея

**«Gym»** — тестовый уровень с эталонными метриками: линейка (расстояние), рамка (окна, двери, укрытия), сфера (AoE, дистанции), заметки.

#### Прототипирование и блокинг

- Блокинг = грубая геометрия для тестирования геймплея до финального искусства
- Форма следует за функцией (form follows function) — сначала геймплей, потом визуал
- Задник (backdrop) — визуальный контекст уровня (горы, горизонт)
- Проверка масштаба (check the scale) — соответствует ли блокинг реальным пропорциям
- Пустое пространство (empty space) — не заполнять всё; пустота = дыхание
- Итерация и плейтестинг — основной цикл улучшения

### Раздел 2: Навигация и различимость (Navigation & Distinction)

#### Восприятие (Perception)

**Проблема**: восприятие глубины и масштаба в играх ≠ реальное. Причины:
- Игрок видит экран с камерой, а не мир напрямую
- Камера может быть отсоединена (3-е лицо) — ещё сложнее оценить расстояния
- 2D платформер легче для оценки расстояний, чем 3D (горизонтальное vs глубинное измерение)

**Решения**:
- Объекты известного размера (футбольный мяч) для оценки расстояний
- Линейные элементы с повторяющимися сегментами (забор, труба, ковёр)
- Осторожность с объектами переменного размера (дерево — маленькое близко или большое далеко?)
- Параллакс (foreground / midground / background) для передачи глубины
- Предметы в коридорах, указывающие на продолжение пути (неполный труп, ковёр за углом, свет из-за поворота)

#### Читаемость (Readability)

Читаемость = способность игрока различать элементы окружения. Проблемы:
- Всё сливается (зелёно-коричневая растительность с тенями)
- Визуальный шум (vegetation + shadows = перегруз)
- Необходимость UI-элементов (стрелки, спец-зрение) как «костыль»

**Решения**:
- Снижение визуальной сложности: минимализм, десатурация окружения, высокая насыщенность персонажей
- Примеры: TF2 (бледное окружение + яркие персонажи), Rainbow Six: Siege (тёмные персонажи + светлое окружение)
- Цветовая гармония: низкая насыщенность = спокойствие, высокая = шум
- Контраст: важные элементы должны выделяться

#### Ориентация (Orientation)

**Ориентирные точки (Landmarks)** — микро / мезо / макро:
- **Микро-ориентиры**: объекты для локальной навигации (знак, ящик, дверь)
- **Мезо-ориентиры**: ориентиры области (часовая башня, кран)
- **Макро-ориентиры**: ориентиры всей карты (гора, небоскрёб)

**Сигнальная разметка (Signposting)**: более прямая форма ориентирования, «говорящая» с игроком. Буквы на бомб-сайтах CS:GO, стрелки, отметки на земле. Риск: нарушение 4-й стены, если не вписывается в мир.

**Точка обзора (Vantage point)**: место, откуда игрок может осмотреть территорию, сориентироваться и спланировать подход. Обычно возвышенность, но может быть и комната с окном.

#### Управление вниманием (Guidance)

**3 способа направления игрока**: UI, внутриигровые визуальные элементы, нарратив.

**Предостережения**:
- Не переоценивать направляющие линии (leading lines) — в игре множество линий, и большинство не направляют
- Корреляция ≠ причинность: то, что игрок пошёл по «линии», не значит, что линия его направила
- Дизайнерское предубеждение: мы видим закономерности, которых игрок не замечает

**Инструменты направления**:
- **Внимание и заметность (saliency)**: яркое, движущееся, контрастное — привлекает внимание
- **Визуальный язык**: белый шёлк/царапины в Uncharted, жёлтые метки в God of War, красные бочки = взрывоопасные
- **Nope zone**: области, которые визуально «отталкивают» (опасность, тупик, неправильный путь)
- **AI-направление**: враги/союзники как визуальный и звуковой ориентир
- **Хлебные крошки (breadcrumbs)**: мелкие объекты, ведущие по пути (монетки, трупы, капли крови)
- **Дразнение (teasing)**: показ цели издалека, чтобы создать желание добраться (синий свет вдали, силуэт здания)
- **Prospect & Refuge**: открытые пространства для наблюдения + укрытия для безопасности
- **Контрастирующие пути**: светлый vs тёмный, широкий vs узкий — визуально указывают на разный тип пути

### Раздел 3: Темп и ритм (Pacing)

#### Поток в одиночной игре (Flow in Singleplayer)

Игроки движутся через уровень «как вода, но как машина»:
- **Как вода**: заходят в ближайшие комнаты первыми, не бегают туда-сюда
- **Как машина**: плавные повороты лучше резких; резкий поворот = обрыв линии видимости = потеря уверенности = замедление

#### Ворота и клапаны (Gates & Valves)

**Hard Gate**: полностью останавливает прогресс (найти ключ, нажать выключатель). Дольше обходить. Используется для принуждения к исследованию.

**Soft Gate**: кратковременно замедляет (свалить дерево, ждать NPC). Для паузы, диалога, замедления темпа.

**Valve**: область, закрывающаяся за игроком (прыжок с обрыва, разрушение пути, лаз). Продвигает вперёд, позволяет загружать/выгружать части уровня.

#### Петли (Loops)

Минимизация бессмысленного возврата через пустые области — уровень замыкается сам на себя. Пример: подземелье с кольцевой структурой. Void Bastards и Hitman 2 — «швейцарский сыр» (множество отверстий-проходов).

#### Переработка уровней (Recycling levels)

Повторное использование уровней с изменениями:
- **Сдвиг силы**: атака укрепления → использование пулемёта против подкрепления
- **Проход в обратном направлении**: проникновение в подземелье → побег обратно
- **Повторное посещение**: уровень изменился (открытый мир, God of War — уровень воды в озере)

#### Планирование и структура

**3 ключевых элемента темпа**: интенсивность, разнообразие, время — на микро/мезо/макро масштабах.

**Биты, графики и таймлайны (Beats, Charts & Timelines)**: инструмент планирования темпа. График интенсивности по времени. Цель: чередовать высокие и низкие точки, избегать монотонности.

**Нелинейный темп**: не всегда постоянное нарастание. Ритм может быть: rise-fall-rise (волны), plateaus (плато), spikes (всплески).

### Раздел 4: Усиление впечатлений (Enhancing the Experience)

#### Выбор (Choices)

Значимые решения = основа вовлечения. Если выбор не имеет последствий — он не значим.

#### Аудио и визуалы

**Первое впечатление**: если игроку кажется, что игра/уровень качественные, он будет снисходительнее к мелким недочётам. Dead Space 2: первая декомпрессия — визуально впечатляющая, последующие — упрощённые, но воспринимаются так же из-за первого впечатления.

**Эстетика**: уникальность локации = запоминаемость. Банальные места (фабрики, склады) = забудутся. Комбинация 2-х знакомых вещей = свежесть (Space Western = Дикий Запад + Космос). Примеры: Firefly, Trigun, Starhawk.

**Цвет, освещение и настроение**: цвет и свет = мощный инструмент создания настроения. Контекст определяет восприятие: красный = здоровье или опасность. Сцена в больнице: тёмные коридоры = тревога, яркие пастельные = спокойствие. Spec Ops: The Line — цвет/насыщенность/контраст для эмоций. Mirror's Edge — цвет для чувства места. Journey — цвет для прогрессии.

#### Нарратив

**3 типа нарратива в играх**:
1. **Явный (Explicit)**: кат-сцены, диалоги, цели миссий
2. **Неявный (Implicit)**: следы крови, трофей на стене, окружающий сторителлинг
3. **Эмерджентный (Emergent)**: «истории игроков», возникающие из взаимодействия систем

Для левел-дизайна наиболее эффективен **окружающий сторителлинг** — не прерывает игрока, делает мир живым, вознаграждает внимательность.

#### Эмоции

Эмоции — мощный инструмент. Ключевые техники:
- **Страх/паника/дискомфорт**: тесные коридоры = клаустрофобия, затопление = паника
- **Облегчение**: после тесноты → открытое пространство
- **Акрофобия**: страх высоты (Half-Life 2 — под мостом)
- **Вторжение в личное пространство**: враги рядом = дискомфорт
- **Форма пространства**: квадратная комната = задержка, узкий коридор с целью вдали = движение вперёд

#### Вау-моменты (Wow Moments)

Впечатляющие события для темпа и нарратива: катастрофы, эффектные сцены, висты. Лучше всего — интерактивные (здание рушится вокруг игрока, а не в кат-сцене).

#### Реактивность (Reactivity)

Реактивность = главная сила видеоигр. Мир должен реагировать на действия игрока: физика, разрушения, NPC-реакции. Control: после боя видны последствия — перевёрнутые стулья, повреждённые столы. «Бессмысленные» взаимодействия (осмотр предметов, включение кранов) делают мир живым.

#### Исследование (Exploration)

Вознаграждение за исследование: секреты, альтернативные маршруты, лор. Отсутствие награды → игрок перестаёт исследовать.

### Раздел 5: Дизайн для боя (Designing for Combat)

#### Боевые пространства (Combat Spaces)

**4 стиля игры**:
1. **Рашер (Rusher)**: агрессивный ближний/средний бой по основному пути
2. **Снайпер (Sniper)**: хорошие линии видимости издалека
3. **Ниндзя (Ninja)**: фланговые маршруты, обходные пути
4. **Оппортунист (Opportunist)**: использует интерактивные объекты (взрывные бочки, газовые трубы, сталактиты)

**Ключевые принципы**:
- Предоставлять выбор для разных стилей
- Вертикальность = интерес (плоское пространство = скучное)
- Динамическое боевое пространство: меняется во время боя (разрушение, затопление, подкрепления)
- Избегать предсказуемых паттернов (Enter room → Door closes → Enemies spawn → Defeat → Door open)
- Варьировать масштаб и тип областей

#### Боевые фронты (Combat Fronts)

Чёткое разделение сторон: фронт, фланг, тыл. Без этого = неконтролируемый хаос.

**Нейтральная зона (No Man's Land)**: опасная область между сторонами без явных преимуществ. Может быть непреодолимой (пропасть).

**Перемещение фронта**: во время боя фронт может смещаться (враги отступают, подкрепления прибывают с нового направления). Tomb Raider (2013): бой на двух платформах, сначала дальний бой, затем враги спускаются по верёвкам для ближнего боя.

#### Фланговые маршруты (Flanking)

- Должны служить «мостами» через нейтральную зону
- Укрытия вдоль фланговых маршрутов не должны быть хорошими постоянными позициями
- Укрытия вдоль флангов должны быть со стороны врага (чтобы атаковать его фланг)
- Маршрут должен быть заметен с позиции игрока
- Не должен быть мгновенно доступен — игрок должен сначала пройти через свой фронт

#### Укрытия (Cover)

- Должно быть функциональным: быть достаточным для защиты
- Разные типы: полное / половинное / укрытие от конкретных типов урона
- Размещение: не слишком далеко друг от друга, не слишком предсказуемо
- Высота укрытия влияет на тип защиты (присед за низким, стоя за высоким)

#### Враги и энкаунтеры

- Враги + укрытия: у врагов тоже должны быть укрытия
- Спавн и отслеживание: враги не должны «появляться из ниоткуда» — объявлять прибытие (взрыв стены, десант с корабля)
- Дизайн энкаунтеров: разнообразие в составе врагов, их поведении, условиях среды
- Союзные NPC: не мешать игроку, помогать органично

### Раздел 6: Мультиплеерный дизайн карт (Multiplayer Map Design)

#### Обзор

**Фокальные точки (Focal Points)**: навигационные ориентиры и художественные центры области/карты («маяк», «кран», «док»). Каждая область должна иметь фокальную точку, место для 4–8 игроков, вариацию рельефа и 2 (лучше 3) входа/выхода.

**Точки интереса (Points of Interest)**: желательные области (снайперские позиции, пикапы, бункеры). Должны быть сбалансированы слабостью.

**Вертикальность**: увеличивает выбор и «геймплей на квадратный метр». Разница высот 3м и 6м делает уровни интереснее.

**Укрытия**: игроки не должны иметь слишком длинную непрерывную линию видимости. Большие открытые пространства разбиваются полным укрытием.

**Читаемость**: критически важна в MP. Ночные уровни = плохая видимость = непопулярные карты. King's Row (Overwatch) — ночной, но хорошо освещённый = популярен.

#### Структуры уровней

**Простота = популярность**: популярные MP-карты имеют простую структуру. Сложный лабиринт = трудно запомнить = стресс. 2–3 основных маршрута достаточно. Секретные маршруты = неидеально, если сильно влияют на победу/поражение.

**5 структур мультиплеерных карт**:

1. **Круг (The Circle)**: кольцевая структура основного пути. Эффективна для deathmatch. Пикапы вдоль кольца = движение. Пересекающие пути = переходы между частями кольца.

2. **Восьмёрка (Figure 8)**: два кольца, соединённые пересечением. Хороша для тактической командной игры (CTF, бомба). Пересечение = точка встречи. Turbine (TF2), Train и Office (CS:GO).

3. **Столкновения (Clash Points)**: точки, где команды встречаются при одновременном выходе со спавна. Не должно быть слишком много. Choke Points = узкие области за Clash Points.

4. **Двойное столкновение (Double Clash)**: 2 точки встречи, обычно в форме восьмёрки. Для round-based режимов. Dust (CS:GO), Tyro Station (Gears of War).

5. **Перетягивание каната (Tug of War)**: команды борются за контроль над центральной зоной, продвигаясь к базе противника.

#### Баланс

**Симметрия vs асимметрия**: симметрия = проще балансировать, асимметрия = интереснее, но сложнее.

**Время**: время достижения ключевых точек от спавна должно быть сопоставимым для обеих команд.

**Спавн-поинты**: не должны быть уязвимыми. Защита через клапаны + блокировку линий видимости.

**Potential Player Positions (PPP)**: все возможные позиции игрока в любой момент — инструмент анализа угроз и укрытий.

#### Поток (Flow) в мультиплеере

**Глобальный поток**: размещение пикапов в арен-шутерах.
**Локальный поток**: фокальные точки, преимущество местности.
**Хорошие DM-карты**: связаны везде со everywhere.
**Хорошие CTF-карты**: стратегически блокируют часть связности (флагоносец должен иметь куда бежать, но не где прятаться).

## 5. Рекомендации для внедрения в Gidede

### 5.1. Приоритетные модули

1. **Модуль «Readability Validator»**: на основе принципов читаемости. Вход: скриншот/описание уровня → анализ: контраст персонаж/окружение, визуальный шум, цветовая гармония. Выход: рекомендации по улучшению читаемости.

2. **Модуль «Combat Space Generator»**: на основе 4 стилей игры + combat fronts. Вход: тип энкаунтера, доступные механики → генерация макета боевого пространства с фронтами, флангами, укрытиями, позициями для каждого стиля.

3. **Модуль «MP Map Structure Classifier»**: на основе 5 структур карт. Вход: описание мультиплеерного режима → рекомендуемая структура (Circle для DM, Figure 8 для CTF, Tug of War для payload и т.д.) + шаблон макета.

4. **Модуль «Pacing Planner»**: на основе матрицы 3x3 + beats/charts. Вход: параметры уровня (длительность, жанр) → генерация графика темпа с контрольными точками.

### 5.2. Интеграция с предыдущими книгами

- **6 слоёв пространства (Кадиков)** + **Читаемость (LD)** = Кадиков даёт структуру пространства, LD — как сделать её читаемой
- **4 макета MP (Кадиков)** + **5 структур MP (LD)** = полная таксономия мультиплеерных структур
- **3 типа систем (Селлерс)** + **Gates and Valves (LD)** = Hard Gate = балансирующий клапан в экономике; Soft Gate = временный тормоз; Valve = односторонний поток ресурсов
- **4 стиля игры (LD)** + **113 линз (Шелл)** = линза «игрок как рашер/снайпер/ниндзя/оппортунист» — чеклист для боевых пространств
- **Матрица темпа (LD)** + **Кривые прогрессии (Селлерс)** = темп = проекция кривой прогрессии на временную ось
- **3 типа нарратива (LD)** + **Нарративный дизайн (Андрианова/Яковлева, Кн. 3)** = Explicit = квестовая система, Implicit = окружающий сторителлинг, Emergent = системные взаимодействия
- **Реактивность (LD)** + **Second-order design (Селлерс)** = реактивность мира = проявление эмерджентности на микро-уровне

**Общий вывод**: «LD: In Pursuit of Better Levels» — **практический справочник левел-дизайнера**, который дополняет теоретические книги серии конкретными техниками. Его главный вклад для Gidede: (1) **Читаемость** — тема, не покрытая другими книгами, но критически важная для практики; (2) **4 стиля игры** — типология для генерации боевых пространств; (3) **5 структур MP-карт** — классификатор мультиплеерного дизайна; (4) **Матрица темпа 3x3** — инструмент планирования; (5) **Навигация без UI** — набор техник (breadcrumbs, teasing, nope zones, prospect and refuge), которые можно формализовать в правила AI-генерации. Книга особенно ценна в связке с Кадиковым (Кн. 11): Кадиков даёт теорию пространства, LD — как сделать его читаемым и навигируемым.
