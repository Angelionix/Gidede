     3→## Project Overview
     4→Gidede is a Game Design AI System (Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui).
     5→Source repo: https://github.com/Angelionix/Gidede.git (v0.51.0).
     6→
     7→The original project is a monorepo: Next.js frontend + Python FastAPI backend
     8→(PostgreSQL + pgvector + Redis). **The Python backend cannot run in this sandbox**
     9→(only Next.js is supported), so the backend has been re-implemented as Next.js
    10→API routes under `/api/v1/*` using Prisma (SQLite) and Node's built-in `crypto`
    11→for password hashing + JWT-like tokens.
