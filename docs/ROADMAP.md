# 🎮 Gidede — Game Design AI System: Roadmap

> **Проект**: Интеллектуальная система для генерации и помощи в создании геймдизайна игр  
> **Репозиторий**: https://github.com/Angelionix/Gidede  
> **Дата старта**: 2026-05-16

## Обзор фаз

| Фаза | Название | Статус | Результат |
|------|----------|--------|-----------|
| 1 | Исследование и анализ источников | 🔲 Не начата | База знаний из книг + веб-исследований |

## Зависимости между задачами

```
Фаза 1 (книги 1-6) ──→ Фаза 2 (Библия)
Фаза 1 (книги 7-16) ──→ Фаза 2 (дополнения)
Фаза 2 ──→ Фаза 2.5 (Концепция программы)
Фаза 2 + 2.5 ──→ Фаза 3 (Алгоритмы)
Фаза 3 ──→ Фаза 4 (Разработка)
```

**Книги 1-6 могут анализироваться параллельно**, после их анализа можно начинать Фазу 2, пока анализируются книги 7-16.
