## 1. Общая характеристика книги

Михаил Кадиков — практикующий дизайнер уровней, создавший единственную на русском языке книгу, целиком посвящённую левел-дизайну. Книга охватывает полный цикл создания уровня — от генерации идеи до финальной сборки — и отличается сильным акцентом на пространственное мышление, психологию восприятия и практическую реализацию. В отличие от большинства книг по геймдизайну, которые рассматривают левел-дизайн лишь как один из разделов, Кадиков делает пространственное проектирование центральным объектом анализа.

**Уникальная ценность для Gidede**: книга предоставляет **систематизированный набор пространственных паттернов и принципов**, которые можно напрямую формализовать в алгоритмы генерации уровней. Это единственный источник в библиотеке проекта, который детально описывает: навигационные системы (9 типов путевых знаков), организацию боевого пространства (фокус сражения, линия фронта, укрытия), мультиплеерные планировки (4 классических схемы + 6 принципов баланса), психологию восприятия пространства и цветовоздействие. Книга существенно дополняет левел-дизайновый раздел книги Роджерса (Book 8), углубляясь в пространственную архитектуру и психологию.

## 2. Ключевые концепции и модели

### Глава 1: Введение — Три кита геймдизайна

**Трёхэлементная модель игры**: Игровая концепция (геймдизайнер) + Технология (программисты) + Визуальный стиль (художники) → Геймплей. Дизайнер уровней — это разновидность геймдизайнера, создающая level gameplay на основе core gameplay.

**Разделение core vs level gameplay**: Core gameplay = набор базовых правил и механик, доступных по умолчанию. Level gameplay = геймплей, создаваемый дизайнером уровней через оперирование пространством, объектами и настройками виртуального мира. Чистое поле = уровень без level gameplay; задача дизайнера — обеспечить достаточное количество интересных игровых ситуаций для применения каждой базовой механики.

**Роль дизайнера уровней ≠ художник по окружению**: Дизайнер уровней фокусируется на создании геймплея через пространство, а не на визуальной составляющей. Его обязанности: (1) проектная документация, (2) трёхмерный прототип, (3) настройка логики событий, (4) сотрудничество с художниками, (5) улучшение игрового опыта.

### Глава 2: Идея — Генерация и запоминаемость

**Модель «Основа + Изюминка»**: Любой уровень = основная идея (набор клише, знакомый игроку) + специальный ингредиент (изюминка, обеспечивающая запоминаемость). Без изюминки уровень = безликий набор банальностей.

**6 типов изюминок**:
1. **Контраст тем** — совмещение 2+ контрастирующих тематик (Fallout: ретрофутуризм + постапокалипсис; Crysis: тропики + антарктический холод; Nuketown: идиллический городок + ядерный полигон)
2. **Достопримечательности** — узнаваемые ориентиры (башня Нового Вегаса, Эйфелева башня, засыпанный Дубай)
3. **Выразительный образ** — спецэффекты и освещение (горящий отель L4D2, ливень Hard Rain, концерт Dark Carnival)
4. **Геймплейная находка** — уникальные механики (бал-маскарад Dishonored, фабрика Titanfall 2, прыжки во времени Dishonored 2, циркулярные пилы TF2 Sawmill, авиаудар Half-Life Crossfire)
5. **Необычное в обычном** — бассейн на крыше (Uncharted 2), голова Статуи Свободы на улице (Crysis 2)
6. **«Три в одном»** — комбинация выразительного образа + геймплейной находки + сюжетного повествования (песчаный район Dishonored 2, астероид Call of Duty: IW)

**«Было бы круто, если…»** — принцип генерации идей через мечтания: «В какой уровень мне хотелось бы поиграть?» Оригинальные идеи рождаются в процессе мечтаний о желаемом опыте.

**5 категорий вау-моментов**:
1. **Катастрофы** — природные и техногенные (крушение самолёта L4D2, падение корабля Enslaved)
2. **Гипертрофированный масштаб** — преувеличенный размах происходящего (армада кораблей CoD, титаны God of War 3)
3. **Впечатляющие панорамы** — контраст с предыдущей локацией (Uncharted, Journey)
4. **Шокирующие сцены** — жестокость и насилие для эмоционального удара
5. **Минутка прекрасного** — контраст красоты среди хаоса (сад в BioShock Infinite)

**Структурная роль вау-моментов**: В начале → «подсадить на крючок»; В середине → пик для смены темпа; В конце → «награда» и стимул продолжать.

### Глава 3: Планирование — Процесс проектирования уровня

**4-шаговый процесс планирования**:
1. **Концептуализация** — поиск идеи, тест на пригодность через ключевые вопросы (какая локация? изюминка? геймплей? реализуемость?)
2. **Визуализация концепта** — подбор фото/видео материалов; дизайнер ищет ключевые элементы для геймплея, художник — для выразительного образа
3. **Планирование геймплея** — схематичный план + документ с описанием игрового процесса
4. **Техническая документация** — детальное описание требований (ресурсы, ограничения, скриптовые события)

**Анатомия игрового пространства (6 слоёв)**:
1. **Структурная геометрия** — крупноформные архитектурные элементы (стены, полы, потолки) = каркас уровня
2. **Детали игрового окружения** — мелкие объекты (мебель, декорации, пропсы) = наполнение
3. **Задний план** — фоновые элементы за пределами игрового пространства = глубина и контекст
4. **Освещение** — ключевой инструмент для направления внимания и создания атмосферы
5. **Аудио и визуальные эффекты** — звук + частицы + погода = атмосферность
6. **Игровой функционал** — интерактивные элементы, триггеры, зоны = геймплей

**Функциональность в архитектуре**:
- Принцип «Думай, как архитектор» — форма следует функции: архитектура реальных зданий подчинена назначению (жильё, склад, церковь), и виртуальная архитектура должна аналогично отражать своё назначение
- **Функциональность + геймплей** — пространство обязано быть средой для функционирования игровых механик: если враги прячутся за укрытиями, архитектура должна предусматривать укрытия
- **Логика и здравый смысл** — двери должны вести куда-то, комнаты иметь назначение, лестницы — перила
- **От большого к малому** — проектирование сверху вниз: сначала структурная геометрия → потом детали → потом декор

**Масштаб и пропорции**:
- **Один к одному** — реалистичный масштаб (1 юнит = 1 метр) как отправная точка
- **Пропорции игрового мира** могут искажаться для геймплея: двери шире, потолки выше, коридоры просторнее
- **Масштабирование и геймплей** — изменения масштаба влияют на ощущения: тесные коридоры = клаустрофобия, огромные залы = трепет
- **Габариты персонажей** — ширина, высота в разных положениях (стоя, вприсядку, ползком) = базовые единицы для всех размеров
- **Среда для игровых механик** — размеры пространства диктуются метрикой механик (дальность прыжка, высота перешагивания, скорость бега)

**Модульность в дизайне уровней**:
- Принцип модульности = разбиение на повторно используемые компоненты
- Преимущества: скорость производства, консистентность, оптимизация
- Недостатки: монотонность, ограниченность вариаций
- Решение: творческий подход к комбинированию модулей + декорирование уникальными элементами

### Глава 4: Атмосфера и повествование

**3 принципа создания атмосферы**:

1. **Имитация реальности** — 4 подкатегории:
   - Природные явления и погодные эффекты (смена суток, отражения, дождь, туман)
   - Имитация движения (колыхание листвы, частицы, работающие механизмы) — «дышащий» мир
   - Художественный беспорядок — объекты «не по сетке», хаотичность = жизнь (наклонные здания, округлые коридоры)
   - Звуковой фон — глобальные и локальные шумы, эхо, озвучка взаимодействия

2. **Постоянство и достоверность** — 3 правила:
   - Правило постоянства: если объект выглядит интерактивным, он должен быть интерактивным; если нет — не должен обманывать
   - Визуальный язык: каждый тип объекта имеет предсказуемое поведение (красные бочки = взрываются, зелёные ящики = здоровье)
   - Достоверность: мир должен «убеждать» игрока в своей реальности через внутреннюю логику

3. **Симуляция жизни** — приёмы:
   - Следы присутствия NPC (разбитые лагеря, брошенная еда, потухшие костры)
   - Следы недавних событий (тела, крови, гильзы, разрушения)
   - Динамические элементы (мигающие лампы, капающая вода, периодические звуки)
   - «Живой» фон (NPC-статисты, птицы, животные, далёкие звуки боя)

**Сюжет посредством игрового окружения — 4 техники**:

1. **Фоновое восприятие** — подсознательный анализ деталей окружения, работающий быстрее сфокусированного внимания. Детали «расскажут» о том, что произошло и происходит.

2. **Говорящие улики** — декоративные элементы (пропсы, декали, эффекты), отражающие следы событий. Принцип: игрок посещает локацию → подсознательно анализирует улики → формирует картину произошедшего.
   - *Локальные события* — мини-истории в рамках одного пространства (мальчик над телом в Metro 2033, угрозы в BioShock Infinite, убежища в L4D2)
   - *Глобальные события* — следы масштабных событий, пронизывающие весь уровень (заброшенный город, военные укрепления)

3. **Фокусировка внимания** — приёмы направления взгляда игрока:
   - Световые акценты (подсветка важных объектов)
   - Композиционные рамки (арки, двери, окна как «рамки»)
   - Контраст (яркий объект среди тусклых, движущийся среди статичных)
   - Линии направления (дороги, трубы, заборы ведут взгляд)

4. **Обучение через окружение** — геймплейные подсказки без текстовых сообщений:
   - Dead Space: надписи на стенах о способе борьбы
   - Half-Life 2: убитый зомби лезвием пилы = подсказка к гравипушке
   - BioShock Infinite: ярмарка как обучение механикам

### Психология восприятия — 3 канала

**Восприятие деталей**:
- Первые 15–20 минут = критический период для формирования впечатления о детализации
- Начальные уровни должны быть максимально детализированными
- Округлые формы лучше передают степень детализации, чем прямоугольные
- «Первое впечатление» — первое взаимодействие с механикой/врагом фиксируется как эталон
- В мультиплеере — точки старта должны быть детализированы, т.к. игроки осматриваются

**Восприятие цвета** — 3 функции:
1. **Эмоциональная температура**: тёплые (оранжевый = безопасность, красный = опасность/ярость), холодные (синий = одиночество/изоляция, голубой = прохлада)
2. **Пространственная коррекция**: холодные тона расширяют пространство, тёплые сужают; светлые = лёгкость, тёмные = тяжесть
3. **Идентификация уровня**: уникальная цветовая палитра = запоминающийся образ (Mirror's Edge = красный + белый, BioShock = арт-деко палитра)

**Восприятие пространства** — 6 архитектурных паттернов:
1. **Узкие коридоры** → клаустрофобия, напряжение
2. **Широкие залы** → свобода, трепет, уязвимость
3. **Вертикальность** → мощь, величие, восхождение/падение
4. **Низкие потолки** → давление, дискомфорт
5. **Открытые пространства** → свобода, но потеря ориентации
6. **Замкнутые комнаты** → безопасность, уют, засада

### Психология ужаса — 12 приёмов

1. **Вид от первого лица** — максимальный эффект присутствия (Alien Isolation, RE7)
2. **Вторжение в персональное пространство** — монстры вплотную к лицу игрока
3. **Зона дискомфорта** — локации, эксплуатирующие страхи (клаустрофобия, насекомые, грязь)
4. **Отсутствие контроля** — ограничение свободы действий (связанный персонаж, сломанное оружие)
5. **Непредсказуемый противник** — нестандартное поведение (Alien в Alien Isolation)
6. **«У страха глаза велики»** — воображение страшнее реальности (тени, звуки без источника)
7. **Ложная тревога** — расслабление после фейковой угрозы → настоящий удар
8. **Уязвимый игрок** — ограниченные ресурсы, медленное передвижение
9. **Неуязвимый противник** — враг, которого нельзя убить (только убежать/спрятаться)
10. **Мучительное ожидание** — затяжное нарастание напряжения перед событием
11. **Цена провала** — потеря значительного прогресса при смерти
12. **Некуда бежать** → **Потеря прогресса** — тупики, загоняющие в ловушку

### Геймплейное повествование — 5 техник

1. **Смена активности** — чередование типов геймплея (бой → исследование → головоломка → сюжет)
2. **Многообразие игровых ситуаций** — вариативность в рамках одной механики
3. **«С корабля на бал»** — резкая смена контекста (из боя → в разговор, из подземелья → на поверхность)
4. **Смена декораций** — изменение визуальной темы уровня для предотвращения монотонности
5. **Смена темпа повествования** — переход от быстрого экшена к медленному исследованию и наоборот

### Глава 5: Навигация и читаемость окружения

**9 типов навигационных инструментов**:

**Группа 1 — Графический интерфейс**:
1. **Карты** — глобальная и локальная карты с маркерами
2. **Целеуказатели/маркеры** — расстояние до цели в UI (эффективно в экшене)
3. **Дополненная реальность** — интерфейс, интегрированный в мир (голокарта The Division, линия-путь Dead Space)

**Группа 2 — Путевые знаки (интегрированные в окружение)**:
4. **Композиция, контраст и свет** — световые акценты направляют движение (яркий выход, подсвеченный путь)
5. **Ориентиры** — видимые издалека объекты-маяки (башни, горы, статуи) = «винни» (weenies)
6. **Персонажи** — NPC как путеводные нити (союзники, идущие к цели)
7. **Движение** — анимированные объекты привлекают внимание (вращающийся вентилятор, мигающий знак)
8. **Подбираемые предметы** — разбросанные предметы = тропа из хлебных крошек
9. **Знаки и цветовое кодирование** — стрелки, надписи, цветовые маркеры (красный = опасность, зелёный = безопасный путь)

**8 паттернов организации движения**:
1. **Препятствия и обходные пути** — прямая дорога заблокирована → альтернативный маршрут
2. **Последовательность в исследовании** — уровни выстроены в логическую цепочку
3. **Отсечение предыдущей локации** — закрытие возврата для движения вперёд (обрушенный мост, закрытая дверь)
4. **Петля** — возврат в уже посещённую точку с новыми возможностями (открытая дверь, полученный ключ)
5. **Изменяющиеся условия** — возвращение в знакомое место с новыми обстоятельствами (наводнение, ночь)
6. **Мнимые тупики** — кажущийся тупик скрывает секрет/альтернативный путь
7. **Очевидные границы** — видимые стены мира, не позволяющие выйти за пределы
8. **Негативное пространство** — пустота, определяющая форму доступного пространства

**7 техник поощрения исследования**:
1. **Награда за любопытство** — секрет за внимательность (потайная комната, пасхалка)
2. **Приманка — ценные предметы** — видимые, но труднодоступные предметы (снайпер на вышке → оружие на вышке)
3. **Приманка — досягаемые ориентиры** — видимые издалека объекты, к которым хочется добраться
4. **Поиск тайников и кладов** — скрытые коллекционные предметы
5. **Поиск кодов и ключей** — предметы, открывающие доступ к новым областям
6. **Взаимосвязанные локации** — места, связанные между собой (система шлюзов, лифтов)
7. **Насыщенность пространства контентом** — достаточная плотность интересных объектов для стимуляции исследования

**Визуальный язык — 9 правил**:
1. **Геймплейные возможности** — объекты, с которыми можно взаимодействовать, должны визуально отличаться
2. **Среда для игровых механик** — пространство должно «подсказывать» возможности (труба = укрытие, уступ = лазание)
3. **Геймплейная функция** — каждый интерактивный объект должен иметь понятное назначение
4. **Статус объекта** — визуальное различие состояний (открыто/закрыто, активно/неактивно, целое/сломанное)
5. **Взаимосвязь объектов** — визуальная связь между связанными элементами (кнопка → дверь одного цвета)
6. **Обозначение тайников** — тонкие подсказки для секретных областей (трещина в стене, необычная текстура)
7. **Предупреждение об опасности** — визуальные сигналы угрозы (красные мигающие лампы, пар от пара)
8. **Нарушение принципа постоянства** — любое нарушение привычного паттерна привлекает внимание = инструмент для акцентирования
9. **Правило постоянства** — если объект выглядит интерактивным, он обязан быть таковым; нарушение правила = потеря доверия

### Глава 6: Создание интересного боевого опыта

**Фокус сражения (Combat Focus)** — ключевое понятие:
- Фокус сражения = место на уровне, на котором фокусируется внимание игрока в ходе боя
- **3 ошибки слабого фокуса**: (1) враги вне поля зрения, (2) укрытия разбросаны далеко → огонь со всех сторон, (3) выход за кадром
- **3 правила сильного фокуса**: (1) враги в рамках фокуса, (2) укрытия рядом → нет уязвимости с нескольких сторон, (3) выход в фокусе
- **Смена фокуса** — несколько фокусов размещаются далеко друг от друга; чередование атак между фокусами (Half-Life 2: EP2 — датчики движения в тоннелях)

**Представление противника** — знакомство до боя:
1. Группа врагов эффектно появляется (высадка десанта, взрыв)
2. Быстро занимает выгодные позиции
3. Только потом открывает огонь
→ Игрок получает время для подготовки

**Линия фронта**:
- Линия фронта = воображаемая линия между игроком и противником
- **Фланговые атаки** — враги обходят сбоку, заставляя смещать линию фронта
- **Перенаправление линии фронта** — дизайн уровня должен предусматривать смену направления атаки

**Система укрытий**:
- **Идеальное укрытие**: (1) защищает от огня, (2) позволяет наблюдать за полем боя, (3) позволяет вести огонь из-за него, (4) имеет путь отхода
- **Разновидности**: низкие (присед за ними), высокие (стоя за ними), укрытия-препятствия, укрытия-углы
- **Правила размещения**: (1) каждое укрытие = тактическая возможность, (2) расстояние между укрытиями = дистанция перебежки под огнём, (3) не все укрытия равноценны — лучшие позиции = награда за тактическое мышление

**Постановка сражения**:
- **Волновые атаки** — чередование интенсивности (волна → передышка → волна)
- **Союзники** — NPC-союзники для распределения внимания, обучения тактике, эмоциональной поддержки

**Песочница** — нелинейная боевая арена:
- **«Пришёл, увидел, победил»** — игрока ставят перед ситуацией и дают выбор способа решения
- **Инструменты песочницы** — множество подходов (стелс, лобовая атака, обход, ловушки, окружение)
- **Нелинейная структура** — несколько маршрутов, многоуровневое пространство, скрытые пути

### Глава 7: Мультиплеерный дизайн уровней

**6 принципов честного мультиплеера**:

1. **Читаемость персонажа в окружении** — модель игрока должна контрастировать с фоном:
   - TF2: менее насыщенные текстуры окружения vs яркие модели героев
   - Rainbow Six: Siege: тёмная одежда vs светлые поверхности
   - Приём: атмосферные эффекты (дымка = лучше читаемость силуэтов)

2. **Меньше значит больше** — минимизация визуального шума:
   - Сложная детализация убирается за пределы геймплейного пространства
   - Чистые, светлые поверхности в зоне боя
   - Hawken — антипример: избыточная детализация мешает геймплею

3. **Освещение и погода** — равные условия видимости для всех игроков; одинаковая освещённость, предсказуемые эффекты

4. **Простота планировки** — легко запоминающаяся структура; ключевые маршруты очевидны; минимум мёртвых зон

5. **Скорость движения** — размеры пространства определяются скоростью перемещения; дистанции рассчитываются на основе времени реакции

6. **Пространство для движения** — достаточная ширина коридоров, дверей, укрытий; отсутствие «бутылочных горлышек» (кроме контролируемых)

**4 классических планировки мультиплеерных уровней**:

1. **Циркуляция** — круговое движение игроков по периметру; постоянное столкновение; подходит для deathmatch (UT, Quake)
2. **Столкновение** — два стартовых лагеря + центральная зона боя; подходит для team modes (CoD, Battlefield)
3. **Перетягивание каната** — одна ключевая точка в центре; команды борются за контроль; подходит для domination/king of the hill
4. **Оборона** — одна команда защищает позицию, другая атакует; асимметричные маршруты; подходит для assault/CTF

**6 принципов баланса мультиплеера**:

1. **Зеркальная планировка** — симметричные стороны для равных условий
2. **Расчёт времени** — одинаковое время достижения ключевых точек с любой стороны
3. **Перенос точек возрождения** — динамическое перемещение спавнов для предотвращения spawn camping
4. **Защита точек возрождения** — безопасная зона вокруг спавна; защита отcamping
5. **Точки интереса** — ключевые локации, привлекающие игроков; контроль = преимущество
6. **Поддержка всех стилей геймплея** — пространство для каждого стиля (снайпер, штурмовик, поддержка)

### Глава 8: От прототипа до финальной версии

**Прототипирование геймплея — 8 вопросов**:
1. **Габариты и метрика движения** — ширина, высота, дальность прыжка, наклон поверхности, высота препятствий
2. **Метрика игровых механик** — дальность оружия, радиус взрыва, скорость снарядов, время перезарядки
3. **Комфортная среда для AI** — размеры навигационных сеток, минимальные расстояния для разворота, зоны видимости
4. **Дополнительные механики** — транспорт, интерактивные объекты, физика
5. **Камера** — поведение камеры в замкнутых пространствах, коллизии, скорость следования
6. **Качество контента** — минимальный визуальный стандарт для понимания происходящего
7. **Дополнительный инструментарий** — модели-помощники для проверки метрик
8. **Тест на прочность** — экстремальные сценарии использования уровня

**4-фазный процесс производства уровней**:
1. **Планирование** — документация, зарисовки, концепт-арт
2. **Играбельный прототип** — базовая геометрия + основные механики + тест геймплея
3. **Прототип геометрии** — уточнённая геометрия + освещение + базовое декорирование
4. **Финальная сборка** — полный контент + полировка + оптимизация

## 5. Рекомендации для внедрения в Gidede

### 5.1. Приоритетные модули

1. **Модуль «Level Space Generator»**: генерация пространственной структуры уровня на основе 8 паттернов движения + 6 пространственных паттернов + метрик персонажа. Вход: тип геймплея + эмоция → структура уровня.

2. **Модуль «Combat Space Designer»**: на основе фокуса сражения + линии фронта + системы укрытий. Вход: тип боя + количество врагов → расстановка укрытий, точек появления, маршрутов.

3. **Модуль «Navigation System Selector»**: автоматический выбор навигационных инструментов на основе типа игры (открытый мир → карта + ориентиры; линейный → свет + знаки; хоррор → минимум навигации). Интеграция с 9 типами навигации.

4. **Модуль «Multiplayer Layout Generator»**: на основе 4 классических планировок + 6 принципов баланса. Вход: режим + количество игроков → зеркальная/асимметричная планировка + точки интереса + спавны.

5. **Модуль «Atmosphere Generator»**: на основе 3 принципов атмосферы + психологии цвета + 6 пространственных паттернов. Вход: жанр + эмоция → цветовая палитра + тип пространства + погодные эффекты + уровень детализации.

6. **Модуль «Horror Level Designer»**: специализированный генератор на основе 12 приёмов психологии ужаса. Вход: поджанр хоррора → комбинация приёмов + пространственные паттерны + система ресурсов.

### 5.2. Интеграция с предыдущими книгами

- **«Музыка механик» (Роджерс)** + **8 паттернов движения (Кадиков)** = последовательность механик + пространственная структура = полная генерация уровня
- **Beat Chart (Роджерс)** + **Вау-моменты (Кадиков)** = автоматическое размещение вау-моментов в Beat Chart
- **Machinations (Адамс/Дорманс)** + **Песочница (Кадиков)** = экономическая модель нелинейной боевой арены
- **Кривые стоимости (Шрайбер)** + **Фокус сражения (Кадиков)** = расчёт стоимости боевых столкновений с учётом пространственного баланса
- **Линзы Шелла** + **Психология восприятия (Кадиков)** = линзы как вопросы для каждого аспекта восприятия (детали, цвет, пространство)
- **4 мультиплеерные планировки (Кадиков)** + **3 стиля мультиплеера (Роджерс)** = планировка по режиму (циркуляция → deathmatch, столкновение → team DM, канат → domination, оборона → CTF)
- **Таксономия сред (Роджерс, ~140)** + **Модель «Основа + Изюминка» (Кадиков)** = выбор клише-среды + автоматическая генерация изюминки

### 5.3. Концепция «Эмоционального каркаса уровня»

На основе книги Кадикова можно формализовать **эмоциональный каркас уровня** — структурированную последовательность эмоциональных состояний, через которые проходит игрок:

```
Эмоциональный каркас уровня:
┌─────────┐    ┌─────────┐    ┌──────────┐    ┌─────────┐    ┌──────────┐
│  Хук    │ →  │ Нараст. │ →  │  Вау-    │ →  │ Смена   │ →  │ Награда  │
│ (вау-   │    │ напряж. │    │  момент  │    │ темпа   │    │ (вау-    │
│ момент) │    │         │    │ (пик)    │    │         │    │ момент)  │
└─────────┘    └─────────┘    └──────────┘    └─────────┘    └──────────┘
Начало         Исследование   Центр уровня    Отдых/сюрприз  Финал

Каждый блок → пространственный паттерн + цветовая палитра + тип атмосферы
```

Этот каркас можно алгоритмизировать: AI получает желаемую эмоциональную кривую уровня и генерирует соответствующие пространственные решения, цветовые схемы и типы атмосферы из моделей Кадикова.

**Общий вывод**: Книга Кадикова — **ключевой источник по пространственному проектированию** для Gidede. Она заполняет пробел, который не может покрыть ни одна из предыдущих книг: как именно организовать виртуальное пространство для создания конкретного игрового опыта. Если Роджерс (Book 8) даёт шаблоны документов и таксономии (что должно быть в уровне), то Кадиков объясняет, как это пространственно реализовать: 9 навигационных систем, 8 паттернов движения, 6 техник исследования, система фокуса сражения, 4 мультиплеерные планировки, 12 приёмов хоррора, психология цвета и пространства. Особенно ценна модель «Основа + Изюминка» как валидатор запоминаемости и «эмоциональный каркас уровня» как алгоритм эмоционального пейсинга. Книга является незаменимым источником для модулей Level Space Generator, Combat Space Designer и Atmosphere Generator.
